# Apatite Arc

Full-colour Python 3 neon grappling swing arcade for ElbowOS.

Swing from violet pegs on a neon rope, collect mint orbs, dodge rose spikes. Space attaches or releases.

Featured: https://x.com/ElbowOS

Drive reel: https://drive.google.com/file/d/116TFACrNSeW0n0y0QlsYPRhaM9h3FROq/view

## Play

```
pip install -r requirements.txt
python3 apatite_arc.py --play
```

## Record 9:16 reel

```
python3 apatite_arc.py --record
```

Needs Python 3.10+ and pygame. Headless record uses SDL dummy + ffmpeg.
